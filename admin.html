Conectar ao GitHub

Só precisa fazer uma vez em cada aparelho.
  1. No GitHub, abra Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque o repositório do site.
  3. Em Permissions → Contents, escolha Read and write.
  4. Gere o token, copie e cole abaixo.
